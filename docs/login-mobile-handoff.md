# دخول الموبايل — ساسكي

الفرع `avg-sasuke`. تعديل واجهة، لا تغيير بالمصادقة أو الخادم.

- المشكلة ليست حجم الخط وحده: حجم input الأدنى داخل flex ومسار grid التلقائي كانا يوسّعان البطاقة بالشاشات الصغيرة. صارت البطاقة والحقول تنكمش حسب عرض الشاشة، مع تمرير رأسي بدون تجاوز أفقي.
- viewport خاص بالدخول: initial-scale=1 وmaximum-scale=1 وuser-scalable=no وviewport-fit=cover. يسترجع المحتوى الأصلي عند مغادرة الصفحة، فلا يفرض منع التكبير على النظام كله.
- touch-action: pan-y وtext-size-adjust:100% داخل الدخول فقط.
- حقول الدخول الاعتيادية وحقول الستارة 16px. تصحيح تعارض dark mode الذي كان يلوّن حقل الدخول المضيء بخلفية غامقة.

الفحص: tsc وeslint وbuild، وChromium بمحاكاة هاتف لمس بعروض 277/320/375/390/430/844/1366، تركيز وكتابة بالاسم والرمز وإظهار الرمز وإخفاؤه، وفشل دخول اصطناعي. جميع الحقول داخل البطاقة، بلا تجاوز عرض ولا تغيير scale. تجربة الستارة وخط حقولها أيضاً. البيانات كلها وهمية، ولا حساب حقيقي استُخدم.

إعادة الفحص مع Vite شغّال:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node scripts/check-login-mobile.cjs
```

اختياري: LOGIN_URL وCHROMIUM_PATH. الصور `/tmp/login-{narrow,mobile}-fixed.png`.

المتبقي: تجربة Safari/آيفون فعلي، لأن Chromium لا يثبت تصرف كيبورد iOS، والمتصفح قد يتجاوز قيود viewport لإعدادات الإتاحة. لا نشر على prod؛ ناروتو يدمج ويفحص، وبعد الموافقة يحتاج build على السيرفر.
