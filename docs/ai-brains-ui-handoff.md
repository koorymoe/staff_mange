# من ساسكي إلى لوفي — دماغين + بث + اقتراحات (10-28)

الفرع `avg-sasuke` مبني على `avg` عند `db1e5066`. لا تغيير بالخادم أو الترحيلات.

## توضيح الصلاحيات المعتمد من لوفي أثناء الشغل

`GET /api/ai/status` **يبقى للمالك وحده**، لذلك بطاقات الدماغين وتعديل السقوف داخل `OwnerAgents` فقط. ما نفتح المسار للأدمن وما نجرّبه ونتلقى 403. صفحة الاقتراحات ومحادثة ماتركس تبقيان للمالك وADMIN. هذا تصحيح للتوجيه الأول، حسب رد لوفي المنقول من دازاي بهذه الجلسة.

## المنجز

- رسالة ماتركس تظهر قبل انتظار إنشاء المحادثة. جلب تاريخ المحادثة الجديدة ما يطمس الرسالة المحلية. التنقل بين المحادثات مقفول أثناء البث، وجلب سجل فاشل يمنع الإرسال حتى إعادة الجلب. الجلب بـalive وعدّاد تحديث.
- `fetch` POST بتوكن الجلسة وreader، وليس EventSource. محلّل SSE منفصل يجمع حدود الأحداث المتقطعة وUTF-8 وCRLF، ويقبل تعليقات/أسطر SSE غير البيانات.
- قطع التفكير تتراكم، وأحداث الأدوات تضيف `🔎 checking …` مع عدّاد استدعاءات. صندوق صغير رمادي LTR، وبعد done ينطوي إلى `Thought for Ns · N tools`، قابل للفتح.
- text يستبدل الجواب بالكامل، وdone يستبدل البطاقة بالرد المحفوظ ومعرّفه الحقيقي، حتى التصحيح ينادى على id الصحيح. الرد الجزئي/الموقوف ما عنده أزرار تصحيح.
- إيقاف بـAbortController، ويشمل إنشاء المحادثة إن كان معلقاً. الطلب يُلغى أيضاً عند مغادرة المكوّن. زر الإيقاف له key مستقل وpreventDefault حتى تبديله بزر إرسال ما يسبب إعادة إرسال آلية (انكشفت بالاختبار وانصلحت).
- error داخل SSE، وخطأ JSON قبل البث، وEOF بلا done يرجعون النص/المرفق للخانة ويعرضون الخطأ. لا retry آلي. السؤال يبقى ظاهراً، لأن الخادم ممكن حافظه قبل فشل الرد؛ الإيقاف يوضّح هذا. Thinking محلي بعرض الجلسة فقط، مو محفوظ بـlocalStorage ولا قابل للاسترجاع من التاريخ حالياً.
- بطاقتا الداخلي/الخارجي من brains بحالة الخادم، صرف/سقف بشريط لا يتجاوز 100%، والأرقام معزولة LTR حتى RTL ما يعكس ترتيبها. الداخلي يعرض chatModel، مع موديل باقي المهام إن اختلف. المالك يعدّل السقف من 0.1 إلى 50، وبعد الحفظ تتحدث الحالة. القيم الغائبة تظهر —، مو أصفار مخمّنة.
- `/ai-suggestions`: البطاقات والوكيل والتفاصيل والحالة وعلامة البرمجة، فلاتر الكل/يحتاج برمجة/الجديد، وقرار ACCEPTED/REJECTED/DONE بتأكيد داخل الصفحة. الفلاتر محمية من الإجابات القديمة، والخطأ لا يعلن نجاح قرار. التأكيد يوضح أن تغيير الحالة ليس تنفيذ كود.
- رابط وبطاقة من مكتب المدير، route بحارس ADMIN وحارس داخل المكوّن، وهدف إشعار AI_SUGGESTION بداخل Layout.

## الفحص

نجحت tsc وeslint وbuild وdiff check. Chromium ببيانات وجلسات **اصطناعية**، بعرض 390 و1366 والوضع الليلي:

- تأخير إنشاء المحادثة مع رسالة فورية، وعدم جلب تاريخ يطمسها.
- SSE مجزأ بايتاً بايتاً (العربية وCRLF)، تفكير متراكم وأداة، واستبدال text لا جمعه، وdone مطوي ثم فتحه، وتصحيح على id المحفوظ.
- إيقاف مع تحقق AbortSignal وعدم أي إعادة إرسال، SSE error، JSON 429، وانقطاع بلا done؛ النص يرجع بكل الحالات.
- سقف المالك، عرض chatModel، شريط 50% وتجاوز السقف محصور عند 100%، ومنع إرسال قيمة أصغر من 0.1.
- ADMIN لا ينادي status أو budgets أو أسماء الوكلاء. مسارات الاقتراحات تعمل له، مع سباق فلاتر متعمد، وقبول/رفض/تم، وفشل قرار ثم إعادة محاولة صريحة.
- موظف غير مخوّل: صفر طلبات API من المكوّنات الثلاثة. تباين نص Thinking في النهاري والليلي مقاس من ألوان المتصفح، فوق 4.5:1.
- أُعيد فحص شاشة الصلاحيات السابقة أيضاً. حدّثت fixture الاختبار فقط لأن avg صار يسمح GET /ai/agents للأدمن؛ ما تغيّر أي كود بشاشة الصلاحيات بهذه الدفعة. هذا مسار أسماء الوكلاء، مو GET /ai/status الذي يبقى للمالك حصراً.

إعادة الاختبار، مع Vite شغال:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node scripts/check-ai-brains.cjs
```

اختياري: BRAINS_BASE_URL وCHROMIUM_PATH. الاختبار يعترض API ويولّد ReadableStream اصطناعياً؛ يثبت سلوك الواجهة والمحلّل، **مو بثاً حيّاً من مزوّد الذكاء أو عبر بروكسي الإنتاج**. صور المعاينة في `docs/ai-brains-ui-previews/`.

## قبل الدمج/الترقية

- لوفي/ناروتو يفحص البث الحقيقي، إعدادات البروكسي وعدم تجميع SSE، زمن الانتظار، قطع الاتصال، وحفظ الرد والتصحيح، مع حسابي OWNER وADMIN. وأيضاً الضغط على إشعار AI_SUGGESTION من النظام الكامل.
- ملاحظة خادم: SetBudget حالياً يرفض <=0 بدل <0.1، رغم نص العقد. الواجهة تفرض الحد 0.1؛ توحيد التحقق بالخادم عند لوفي.
- إيقاف fetch لا يَعِد بإلغاء إجراء/كتابة سبق أن تمت بالخادم أو إيقاف كلفة المزوّد بعد وصول الطلب؛ يعتمد ذلك على تمرير سياق الإلغاء بالخادم. ما أضفت مسار إلغاء مخمناً.
- بث ايريس خارج هذه الدفعة؛ العقد يقول ينتظر مساره من لوفي.
- لا رفع إلى prod؛ يحتاج الدمج والفحص ثم نشر وبناء على السيرفر بعد الموافقة.
