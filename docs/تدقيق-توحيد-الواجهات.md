## خطة التنفيذ (مرحلة مرحلة، كل مرحلة تنفحص وتنرفع)
1. **الأساس** — مكوّنات موحّدة بـ`src/ui`: `PageHeader`، `Button`، `DeleteButton`، `StatusBadge`، `Loading`/`Empty`، `notify` (بدل alert)، `Modal`، `StatCard`، `utils/date.ts`.
2. **الرأس والرجوع** بكل الصفحات (١٨٧).
3. **الأزرار والحذف** (لون واحد، حذف دائماً بتأكيد).
4. **الحالات والأدوار** (مكان واحد).
5. **الأخطاء**: `alert()` ← تنبيه موحّد.
6. **التواريخ والفلوس**.
7. **التحميل/الفراغ، النوافذ، البطاقات**.
8. **الوضع الليلي** (آخر شي، لأنه يعتمد على كل الي قبله).

كل مرحلة: فحص بالمتصفح (لقطات قبل/بعد)، اختبارات، وسطر بسجل الوقت.
