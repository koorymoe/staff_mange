## ب. الصلاحيات — كل طرق الوصول رغم الشيل
- **المنصب بالهيكل يعطي دور كامل** (الأقوى): وحدة المراقبة ← MONITOR (يفتح ١١٦ قاعدة)، الحسابات ← FINANCE، إدارة الكوادر ← HR_COORDINATOR، الجودة ← QUALITY_ENGINEER، المشتريات، المشاريع… ومدير/نائب الإدارة ياخذ أدوار كل وحداتها. شيل الصلاحيات ما يأثر على هذا أبداً.
- **صلاحية «monitoring» وحدها تخلي الموظف مراقب كامل** بكل الفحوصات.
- **تسليم الموظف (handover)** ينسخ دور ومسؤوليات وصلاحيات المسلِّم للمستلم، بدون ما يشيك المشالة.
- الوكالة (مدير بالإجازة) تنطي أدوار رأس الوحدة فوراً.
- (مو السبب) الجلسة ما تخزّن الصلاحيات — السيرفر يقراها كل طلب.
- **لنرجس بالذات:** شاشة الإنجازات تنفتح بـ: الدور MONITOR (منصب بالمراقبة أو مدير/نائب إدارة الإدارة)، أو صلاحية monitoring/auditing/mon_attendance، أو تسليم من مراقب.

- **صفحات تفاصيل بلا رجوع:** سيت المخططات، مكتب الإدارة، إضافة فورمة سريعة، فاتورة ليدر جديدة، عرض سعر جديد، عرض سعر المشروع.

- **اسم القائمة ≠ عنوان الصفحة:** ١٨ صفحة (مثل «العملاء» ← «الزبائن»، «مهام الميدان» ← «مهامي»، «جرد الأدوات» ← «إدارة المخزون والأدوات»)، و١١ صفحة بلا عنوان أصلاً.
- **ناقص بالعمليات:** معارض/دراسات/مواد تدريب/خدمات/إعلانات تنحذف بس ما تتعدّل؛ زبائن/موظفين/أقسام/شكاوى تتعدّل بس ما تنحذف.
