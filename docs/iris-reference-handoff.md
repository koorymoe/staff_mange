# ايريس — تطبيق مرجع دازاي البصري

الفرع `avg-sasuke` فوق `1130da80` من `avg`.

- اسم ايريس مع شعار الأماني الأصلي واسم الشركة، وجرس يفتح التذكيرات. حالة الاتصال تشير لوصول النظام والشبكة، مو لتوفر نموذج الذكاء.
- بطاقة اجتماعات اليوم محسوبة من `secretary/agenda`: مقابلات وضيوف بتاريخ بغداد لليوم. تضغطها وتفتح جدول أعمالي.
- المهام العاجلة من `GET /extra-tasks`: الأولوية URGENT والحالة NEW أو IN_PROGRESS فقط. المسار مسموح للمالك ومدير النظام، والواجهة كلها محروسة قبله. الضغط يفتح قائمة داخل التطبيق؛ لا تعديل أو إنجاز لمهمة موظف من هذه القائمة.
- وقت فشل الجلب يعرض العداد «—»، وما يخمّن صفراً.
- خلفية زرقاء فاتحة وبطاقات زجاجية، ردود بيضاء ويا صورة الشعار، رسائل صادرة زرقاء، وبطاقات تفاصيل منظمة. بطاقة اجتماع تفتح الجدول، بدون ادعاء تأكيد موعد غير مدعوم.
- اقتراحات ترتيب اجتماع/تلخيص تقارير/إعداد رسالة ترسل الطلب لايريس، وصندوق الكتابة والمايك والإرسال ثابتين. أقسام الدرج الأربعة محفوظة.
- ماكو مرفقات أو إشعارات قراءة شكلية أو أرقام ثابتة مقتبسة من الصورة.

الفحص: tsc وeslint والبناء؛ Chromium بـ390px و320px و1366px، نهاري/ليلي، تمرير داخلي بلا تمرير أفقي، حقول 16px، عمل البطاقات والجرس والاقتراحات، العدادات واستبعاد المنجزة/غير العاجلة، فشل الجلب، ومنع الطلبات لغير الإدارة. ردود API اختبارية؛ الفحص الحي عند ناروتو.
