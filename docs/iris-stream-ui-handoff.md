# من ساسكي إلى لوفي — ايريس الحية (10-28)

الفرع `avg-sasuke`، بعد دمج `avg` بعقد `30446a4c`. واجهة فقط، بلا تعديل بالخادم أو الترحيلات.

## المنجز

- النص والبصمة يستعملان `POST /api/secretary/message?stream=1` عبر fetch + reader وتوكن الجلسة. JSON `{text, conversationId}` أو FormData بملف `file` ومعرّف المحادثة؛ حد multipart ينحط من المتصفح، مو هيدر يدوي.
- نفس محلّل ماتركس صار عاماً بنوع done متغير وتحقق خاص بكل جواب. واجهة ماتركس وتوقيع قارئه القديم باقين، حتى ما يختلط reply الخاص بايريس مع message الخاص بماتركس.
- رسالة النص تظهر فوراً، والبصمة تظهر كرسالة صوتية قيد التحويل فور انتهاء التسجيل. النص الحقيقي للبصمة يأتي من transcript داخل done، بدون تخمين.
- Thinking رمادي LTR، تراكم قطع التفكير وأسطر checking للأدوات، عدّاد وقت وأدوات، وtext يستبدل الجواب بالكامل. done يطوي التفكير ويستبدل العنصر المحلي بالرسالة المحفوظة ومعرّفها، ويعرض cards وproposal كما بالسابق.
- المحادثة الجديدة تتبنى conversationId من done بلا جلب تاريخ يطمس البطاقات/المقترح/التفكير. اختيار المحادثة وتخزينه وقوائمها باقين؛ التبديل أثناء البث مقفول. التمرير داخل مساحة الرسائل فقط، بدون سحب الصفحة كلها مع كل قطعة.
- إيقاف بـAbortController، مع key منفصل وpreventDefault حتى ما يعيد إرسال الطلب عند تبديل الزر. الإلغاء عند مغادرة المكوّن أيضاً.
- JSON error قبل البث، SSE error، أو انقطاع بلا done: النص يرجع للخانة. الرد الجزئي يبقى معلّم أنه غير مكتمل. ماكو retry آلي.
- الصوت المتوقف/الفاشل يبقى Blob مؤقتاً بالذاكرة لإعادة محاولة **صريحة** أو حذفه. يتشال من الواجهة عند تبديل المحادثة أو نجاح الإرسال أو اختيار طلب جديد؛ لا يُكتب إلى localStorage أو ملف من الواجهة. ما نَعِد بحذف نسخة سبق رفعها إلى الخادم.
- تنبيه واضح: إيقاف/انقطاع البث مو تراجع عن إجراء سبق أن نفّذه الخادم. لا POST إضافي لتأكيد مهمة من الواجهة قبل قرار المستخدم؛ المقترح غير المكتمل يظهر بنافذته الأصلية، وإجراءات الخادم المكتملة تظهر ببطاقاتها.
- حارس OWNER/ADMIN باقٍ. لا أي طلب من موظف غير مخوّل. هيكل ايريس والكيبورد والحقول 16px باقين.

## الفحص

tsc وeslint وbuild وdiff check، ومتصفح Chromium بمحاكاة بيانات وجلسات وصوت وReadableStream اصطناعي:

- رسالة فورية، تجزئة الأحداث بايتاً بايتاً (UTF-8 وCRLF)، تراكم التفكير/الأدوات واستبدال text، وطي التفكير ثم فتحه.
- done يعرض البطاقة والمقترح ومرشحين اثنين، بلا confirm تلقائي. لا جلب تاريخ يمسح جواب محادثة جديدة، ومعرّف المحادثة ينحفظ للحساب الصحيح.
- FormData يحمل ملف الصوت ومعرّف المحادثة؛ transcript ينظهر بعد done، وتتوقف مسارات المايك بعد التسجيل.
- إيقاف بلا إعادة إرسال، JSON 400 وSSE error وEOF، استرجاع النص، إعادة صوت صريحة من الذاكرة، وAbort عند unmount.
- ADMIN يعمل على مسار ايريس، وغير المخوّل صفر طلبات. عرض 390px و1366px والوضع الليلي.
- اختبار المحادثات السابق حدّثت fixture ماله إلى SSE وأعدت تشغيله (إنشاء/تبديل/تسمية/حذف/صوت). وأعيد اختبار بث ماتركس والدماغين حتى نثبت عدم كسر القارئ المشترك.

إعادة الفحص مع Vite شغال:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node scripts/check-iris-stream.cjs
PLAYWRIGHT_MODULE=/path/to/playwright node scripts/check-iris-conversations.cjs
PLAYWRIGHT_MODULE=/path/to/playwright node scripts/check-ai-brains.cjs
```

اختياري للاختبار الجديد: IRIS_BASE_URL وCHROMIUM_PATH. الصور الاصطناعية في `docs/iris-stream-ui-previews/`.

## المتبقي قبل الترقية

- لوفي/ناروتو يفحص الخادم الحقيقي عبر البروكسي، والبصمة الحقيقية على Safari، والبطاقات والمقترح وحفظ المحادثة، بمالك وأدمن.
- اختبار انقطاع/إيقاف طلب نفّذ إجراء بالفعل، وتأكيد أن عرض التاريخ يبين الحالة الفعلية. إلغاء fetch ما يثبت rollback ولا يضمن إيقاف كلفة المزوّد؛ هذا يعتمد على معالجة الإلغاء بالخادم.
- الاختبارات هنا صناعية، مو استدعاء لمزوّد ذكاء ولا تجربة آيفون فعلي. لا رفع على prod؛ يحتاج الدمج والفحص ثم النشر والبناء بالسيرفر بعد الموافقة.
