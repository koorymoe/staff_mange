## طريقة التنفيذ للقسم ١ (بعد الموافقة)
1. **الترحيل:** عمود `archivedAt` (و`archivedById`) لكل جدول بالقسم ١، إذا ما موجود. **وينضاف لموديلات Go** لأن الاستعلامات `SELECT *`.
2. **`Delete`:** يصير `UPDATE … SET "archivedAt" = now()`. نفس الزر ونفس الرسالة للموظف.
3. **القوائم والعدّادات:** كل استعلام قائمة أو عدّ لهالجداول يضيف `"archivedAt" IS NULL`. هذا أكبر شغل، لأن الجدول ممكن ينقرا من ١٠ أماكن.
4. **شاشة «المحذوفات» للمالك:** يشوف بيها المعطّل ويرجّعه.
5. **الترتيب، جدول جدول:** نبدي بالفواتير والمشاريع والساعات، وكل جدول كومت لحاله، ويا فحص قبل/بعد إن القوائم ما تغيّرت.
