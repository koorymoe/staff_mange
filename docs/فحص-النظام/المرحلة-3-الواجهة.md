## F-01 · 🔴 عالي — صفحة الصلاحيات: سباق يمنح موظفاً صلاحيات موظف ثاني

**وين:** `frontend/src/pages/PermissionsPage.tsx:47-64`

```js
useEffect(() => {
  if (!selectedEmployeeId) { ... return }
  setPermsLoadFailed(false)
  api.getEmployeePermissions(selectedEmployeeId)
    .then((perms) => setEmployeePerms(perms.map((p) => p.name)))   // ← بلا حارس
    .catch(() => { setEmployeePerms([]); setPermsLoadFailed(true) })
}, [selectedEmployeeId])
```

**شنو صاير:** ماكو حارس إلغاء. فلو الأدمن ضغط على موظف وبعدها بسرعة على موظف ثاني:

| # | الحدث |
|---|---|
| ١ | ضغط على الموظف (أ) → ينطلق طلب (أ) |
| ٢ | ضغط بسرعة على الموظف (ب) → `setPermsLoadFailed(false)` وينطلق طلب (ب) |
| ٣ | رد (ب) يوصل → `employeePerms` = صلاحيات (ب) ✅ |
| ٤ | رد (أ) يوصل **متأخراً** → `employeePerms` = صلاحيات **(أ)** ❌ والشاشة تعرض (ب) |
| ٥ | `permsLoadFailed = false` — لأن **الطلبين نجحا**. فالزر شغّال وماكو أي تحذير |
| ٦ | ضغط «حفظ» → `setEmployeePermissions(ب, صلاحيات_أ)` |

**والخادم يستبدل مو يضيف** — الكاتب نفسه يوثّقها بالسطر ٥٩-٦٢:

> 🔴🔴 «ما انجلبت» **مو** «ماكو صلاحيات»: الحفظ يرسل القائمة كاملة والخادم
> **يحذف كل صفوف الموظف** ويعيد إدخال المؤشَّر بس.

**الأثر:** الموظف (ب) **يفقد كل صلاحياته ويستلم صلاحيات (أ)** — بهدوء، بلا خطأ ولا تحذير.
ولو (أ) عنده صلاحيات أوسع، هاي **ترقية صلاحيات بالغلط**.

**🔴 وليش هاي بالذات مؤلمة:** الكاتب **شاف الخطر وحرس منه** — `permsLoadFailed` وشريط
تحذير أحمر وزر مقفول (أسطر ٣٧٥-٣٨٠ و٤٩٠). بس الحارس يمسك مسار **الفشل** وبس.
ومسار السباق يمرّ من جنبه لأن **الطلبين نجحا** — فما ينكشف أبداً.

وهاي حرفياً الحالة الي يحذّر منها `AGENTS.md`:
> «تبديل فلتر بسرعة بلا هاي الحماية يخلّي جواب قديم يطمس الجديد — والموظف يتخذ قرار على بيانات غلط»

**الحل:** ثلاث سطور — حارس `alive` بنفس النمط المستعمل بـ`SalesBooking.tsx:131`:
```js
let alive = true
api.getEmployeePermissions(selectedEmployeeId)
  .then((perms) => { if (alive) setEmployeePerms(...) })
return () => { alive = false }
```

## F-03 · 🟠 متوسط — ٥٦٪ من معالجات الأخطاء تخفي الفشل

**القياس على ٢٢٤ نداء `.catch`:**

| النمط | العدد | النسبة |
|---|---|---|
| ✅ يعرض رسالة للمستخدم | ٤٥ | ٢٠٪ |
| 🟠 يحط حالة فاضية — الفشل يبين «ماكو بيانات» | ٧٧ | ٣٤٪ |
| 🔴 فاضي تماماً — يبلع بلا أي أثر | ٤٩ | ٢٢٪ |
| ◻️ غير ذلك | ٥٣ | ٢٤٪ |

**الأثر:** المستخدم ما يفرّق بين «السيرفر واقع» و«ماكو شي هنا».
والـ٧٧ هي الأخبث: `.catch(() => setX([]))` تخلّي فشل الشبكة يطلع قائمة فاضية طبيعية،
فالموظف يتخذ قراراً على «ماكو بيانات» وهي موجودة.

**والمستودع نفسه يعرف إن هذا خطر** — نفس تعليق `PermissionsPage`:
> «ما انجلبت» **مو** «ماكو صلاحيات»

المبدأ مكتوب ومفهوم، ومطبَّق بموضع واحد — و**٧٧ موضع يسوّون العكس بالضبط**.

**وهاي العائلة الي علّگت شاشة المراقب** (C-01): `.catch(() => {})` بلع فشل الحجز
وترك الطبقة السودة معلّقة. ومترابطة مع **B-03** بالباك إند (٢٦٣ ردّ `500` مقابل ٢٩ `404`) —
الخادم يرجّع خطأ مضلِّل، والواجهة تبلعه بصمت. الطرفان يضيّعان نفس المعلومة.

## F-05 · 🔵 منخفض — ٤ فحوص `role === 'OWNER'` ميتة

`Layout.tsx:127` هو المكان **الوحيد** الي يقلب الدور:
```js
const normalized = emp && emp.role === 'OWNER'
  ? { ...emp, actualRole: 'OWNER', role: 'ADMIN' } : emp
```
فـ`role === 'OWNER'` **ما تتحقق أبداً** داخل النظام.

| الموضع | الأثر |
|---|---|
| `pages/BookingsList.tsx:113` | `const owner = employee?.role === 'OWNER'` — دائماً `false` |

**الأثر الفعلي: صفر.** الأربعة كلهن يمرّون عبر `isAdmin`
(و`isAdmin = role === 'ADMIN'` صحيحة للمالك بعد التطبيع).
مذكورة **كنظافة مو كعلّة** — كود ميت يوهم القارئ إنه يسوي شي.

## ✅ الي طلع نظيفاً — وتأكدت منه

- **صفر `dangerouslySetInnerHTML`** و**صفر `eval`** بكل الواجهة — ماكو سطح XSS إطلاقاً
- **صفر صنف `dark:`** بالمكوّنات — قلب الوضع الليلي مركزي ١٠٠٪ بـ`index.css`، والانضباط تام
- **فخ الشفافية محلول** — تأكدت: المستوى `-50` مقلوب **بالمتغيّر** مو بالصنف
  (`--color-slate-50` · `--color-gray-50` · `--color-sky-50` …)،
  فـ`bg-slate-50/50` تنقلب وياه. الحل ذكي ويغطي ٢٠٧ استعمال بضربة وحدة
- **فخ `actualRole` محترَم** — ٤١ استعماً صحيحاً، والأربعة الميتة بلا أثر
- **تقسيم الكود ممتاز** — ١١٣ استيراداً كسولاً بـ`App.tsx`.
  الحزمة الأولى ٤٠٩ ك.ب (١٢٣ ك.ب مضغوطة)، والثقيلات (محرّك الشخصية ٥٦٥ ك.ب ·
  Babylon ٥٢١ ك.ب) **ما تنجلب إلا عند الحاجة**
- `npx tsc --noEmit -p tsconfig.app.json` — **نظيف تماماً**
- `npm run build` ينجح
- التوكن بـ`localStorage` — مقايضة مقبولة هنا: CSP صارم (`script-src 'self'`، بلا `unsafe-inline`)
  **وصفر سطح XSS**، فالخطر الحقيقي مقفول من جهته
