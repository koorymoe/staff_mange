## 🔴 الخيط الي يربط أكثر الملاحظات

**التصميم صحيح — والتطبيق ناقص.**

- تعريف «الحجز الي ينعدّ» معرَّف بملف واحد ممتاز (`booking_delete_filter.go`) — و**٩ عدّادات ما تناديه**.
- `hydrateAll` المجمّعة مكتوبة (`leader_invoice_repository.go:417`) — و**٨ مستودعات** يستعملون الفردية.
- حارس الملكية مكتوب بثلاث دوال بملف المخزون — و**رابعة انفلتت** (`ToolEvents`).
- آخر كومِت صلّح عدّادين بلوحة الترتيب — و**تسعة بنفس العائلة** بقن بملف ثاني.
- حارس السباق مكتوب (`SalesBooking.tsx:131`) — و**٣١ موضع** بلا حارس.
- مبدأ «ما انجلبت ≠ ماكو» موثَّق بـ`PermissionsPage` — و**٧٧ موضع** يسوّون العكس.

وهذا **مو ضعف بالمهارة — ضعف بالشبكة**. ماكو اختبار يمسك «الجولة ما كملت»،
و`repository` على **صفر تغطية**. فكل إصلاح يعتمد على إن الي يسويه يتذكّر كل المواضع.
