# 🏗️ التصميم بنظامنا — الخطتين (دازاي 11-08)

> «لازم نرتب هذا الموضوع بأقوى وأسرع صورة… الخطة الثانية جدولها وخليها مؤجلة».

## الخطة ١ — الحل المؤقت (✅ انبنى 11-08)

**«🏗️ صيت التصاميم»**: كل مشروع وتصاميمه بمكان واحد. ١٥ تخصص:
معماري · إنشائي · توب فيو · ثري دي · ديكور داخلي · سيراميك وأرضيات · شبابيك وألمنيوم ·
كهرباء · كاميرات · شبكات وواي فاي · صوتيات · إنذار حريق · أنظمة ذكية وأقفال · طاقة شمسية ·
مقاولات وجدول كميات.

لكل تخصص:
- **أزرار أدوات** تفتح موقع التصميم بتبويب جديد (تي بي لينك، داهوا، أوتوكاد ويب، سكتش أب…)،
  ويّا **طريقة الإرجاع** لكل أداة. الأدوات تنعدّل من الشاشة («🧰 إدارة الأدوات»).
- **إرجاع الشغل**: لصق `Ctrl+V` · سحب وذب · اختيار ملف · رابط مشاركة.
  الأنواع: صور · PDF · DWG (أوتوكاد) · GLB (ثري دي **ينفتح جوّه النظام**). لحد ٢٤ ميگا.
- **مصمم وموعد** ← يصير **مهمة** بمهامه (تنحسب بتقييمه).
- **مراجعة**: «للمراجعة» ← يوصل للمالك/المدير ومدير الهندسة ووحدة التصميم ← اعتماد (يخلّص المهمة)
  أو إرجاع بملاحظة (حتى بعد الاعتماد).

**ليش مو جوّه النظام مباشرة؟** تي بي لينك (Omada Design Hub)، داهوا، وهيكفيجن **ما ينطون API**
للتصميم — أدواتهم صفحات مستقلة. الاستثناء Autodesk (عارض APS) — للعرض بس وبحساب مطوّر وكلفة.

## الخطة ٢ — محاكاة التصميم جوّه نظامنا (⏸️ مؤجلة)

ويّا ميزة ما عندهم: **أسعارنا وعرض السعر لحاله**.
