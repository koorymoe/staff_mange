## إعدادات
- `ANTHROPIC_API_KEY`: **اختياري**.

- ماكو متغيرات بيئة جديدة غيره.

## خطوات الرفع (لما (ع) يگول)
1. (ع) يحوّل ربط GitHub بـClaude لحساب **amaniabi**.
2. `git fetch new main`. إذا تقدّم، ندمج ونحل التعارضات.
   - **Cartoon Boy ينشال قبل الرفع:**
     - `git rm --cached frontend/public/cartoon-boy-web-ready.glb`.
     - نشيل بند `builtin:cartoon-boy-web` من `EntityLabPage.tsx`.
     - نرفع commit واحد (squash) فوق `new/main`، حتى الملف ما يوصل لتاريخ
       المستودع الجديد أبداً.
3. نتحقق: `go build ./... && go vet ./... && go test ./...`، و`tsc` و`eslint`
   و`npm run build`.
4. `git push new HEAD:main`، فيشتغل النشر التلقائي.
5. نتأكد من الموقع:
   - الترحيلات انطبقت (0300→0303).
   - الدخول يشتغل.
   - `?board=matrix` يفتح.
