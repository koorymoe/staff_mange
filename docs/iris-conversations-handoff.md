# قائمة محادثات ايريس — تسليم ساسكي

الفرع `avg-sasuke` مبني على `avg` عند `ef5e685d`. التوجيه: `sasuke-iris-conversations-brief.md`.

## المكتمل

- زر محادثة جديدة وقائمة بالعناوين والأوقات (بغداد) أعلى الأقسام الأربعة. المختارة مظللة ومحفوظة لكل حساب بـlocalStorage، مع بديل لو التخزين محجوب أو المحادثة المحفوظة انحذفت.
- تسمية داخل الصفحة، وحذف بتأكيد واضح قابل للإلغاء. لا prompt أو confirm.
- النص وmultipart الصوت يحملان conversationId. تحديث القائمة بعد الرد لعرض العنوان التلقائي وترتيب الخادم.
- جلب القائمة والسجل داخل effects بحماية alive. التبديل السريع يلغي تأثير الرد القديم. الإرسال ممنوع أثناء تحميل السجل أو فشله، مع إعادة محاولة، والتبديل ممنوع أثناء إرسال/تسجيل الصوت حتى ما ينرسل للمحادثة الغلط.
- الرسالة النصية الفورية وحالة التفكير وإصلاح الكيبورد السابق باقين.
- صلاحيات OWNER الفعلي وADMIN باقية؛ لا تغيير بالباك إند أو الترحيلات.

## الفحص

TypeScript وESLint وbuild وdiff check. متصفح Chromium على Vite ببيانات اصطناعية: اختيار محفوظ، تبديل سريع مع سجل متأخر، إنشاء، تسمية، حذف/إلغاء، صوت بمحادثة محددة، JSON ومultipart، تحديث العنوان، إعادة فتح، عرض 390px و1366px، ووضع ليلي. نجحت أيضاً اختبارات المرجع والصلاحيات وعدم تجاوز عرض الشاشة ومحاكاة الكيبورد.

اختبار قابل للإعادة (شغّل Vite أولاً):

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node scripts/check-iris-conversations.cjs
```

اختياري: `IRIS_URL` و`CHROMIUM_PATH`. الاختبار يعترض API والمايك بالكامل؛ لا يستعمل حسابات أو أصوات حقيقية، ولا يثبت الربط الحي بالخادم. الصور بـ`/tmp/iris-conversations-{mobile,desktop,dark}.png`.

المتبقي لناروتو: فحص حي على الخادم الجاهز، خصوصاً الصوت الحقيقي على Safari، ثم الدمج. لا ترقية إلى prod؛ ظهور الواجهة بالسيرفر يحتاج النشر والبناء بعد الموافقة.
