# 0004 — عمليات الفلوس تنسجّل مرة وحدة
**الحالة:** ✅ معتمد (تعديلات ٦أ، 11-04)

## السياق
الضغطة المزدوجة، أو النت لما يتقطّع والمتصفح يعيد الطلب، جانت تسجّل نفس الدفعة مرتين.

## القرار
- طلبات الفلوس تمر بوسيط التكرار الآمن. المفتاح هو ترويسة `Idempotency-Key`، وإذا ما موجودة نستعمل بصمة الطلب (الموظف + المسار + الجسم) بنافذة قصيرة.
- الطلب الثاني ياخذ نفس الرد بلا تسجيل جديد. وإذا الأول بعده يشتغل، الثاني ياخذ ٤٠٩.
- ويا هذا قيود بالقاعدة نفسها، مثل فاتورة وحدة لنفس الحجز باليوم.
- المفاتيح تنمسح يومياً بعد يومين.

## وين بالكود
`backend-go/internal/middleware/idempotency.go`. وCORS يسمح بالترويسة بـ `middleware/common.go`.
