# 0007 — أي عمود جديد ينضاف لنموذج Go
**الحالة:** ✅ معتمد

## السياق
أغلب القراءات `SELECT *` ويا `sqlx`. أي عمود بالقاعدة ما إله حقل بالنموذج يفشّل القراءة (`missing destination name`)، والشاشة تفرغ.

## القرار
أي `ALTER TABLE … ADD COLUMN` لازم يكون وياه حقل بنفس الـ `db:"…"` بنموذج `internal/model`، وبنفس الـ commit.

## النتيجة
- الكلفة: ترحيل بلا نموذج يكسر الشاشة بصمت.
- على المدى البعيد (٧ل) القوائم تنتقل لأعمدة محددة.

## وين بالكود
`backend-go/internal/model/`، والترحيلات بـ `internal/database/schema_*.go`.
