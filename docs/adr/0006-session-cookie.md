# 0006 — جلسة بكوكي HttpOnly، بالتدريج
**الحالة:** 🔨 الخطوة ١ منفّذة (٧ي، قرار صاحب النظام 11-04: بالتدريج)

## السياق
التوكن بـ `localStorage` ينقرا من أي سكربت يندس بالصفحة.

## القرار
- **الخطوة ١:** السيرفر يحط كوكي `sm_session` (HttpOnly) ويقبل الطريقتين. والطلبات الي تغيّر شي لازم ترسل `X-Requested-With` كحماية CSRF، والخروج عبر `POST /api/auth/logout`.
- **الخطوة ٢:** بعد أسبوع تجربة (١١ تشرين الثاني)، وبموافقة صاحب النظام، نوقف حفظ التوكن بالمتصفح.

## وين بالكود
`backend-go/internal/middleware/auth.go`، ومسار الخروج، و`serverLogout()` بالواجهة.
