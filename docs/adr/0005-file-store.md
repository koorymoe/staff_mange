# 0005 — الملفات بمخزن الملفات، والقاعدة بيها الرابط بس
**الحالة:** ✅ معتمد (٧ل، 11-05)

## السياق
الصور والعقود والوصولات جانت تنحفظ base64 داخل أعمدة نص. هذا ثگّل القوائم (صور الكل تنزل ويا البيانات)، وثگّل القاعدة والنسخ الاحتياطي.

## القرار
- الرفع يمر بـ `POST /api/files`. النوع ينفحص من المحتوى (صور أو PDF)، والمجلد من قائمة بيضاء. ويرجّع `/api/files/<key>`.
- الواجهة تستعمل `storeFile(file, folder)`، وإذا فشل الرفع ترجع لـ base64 حتى ما يضيع الملف. والعرض دائماً يمر بـ `fileUrl()`، الي يضيف `?ft=` (توكن الملفات).
- **القديم:** `MigrateInlineFiles` بأول تشغيل يحفظ الملف، **يقراه ويقارن البايتات**، وبعدها يبدّل العمود بشرط ما تغيّرت قيمته. وأعمدة المصفوفات تنتقل بأداة `cmd/migratefiles`.
- المخزن R2 إذا انضبط، وإلا القرص المحلي.

## النتيجة
- القوائم والنسخ أخف.
- الكلفة: الملفات صارت لازم تنحسب بالنسخ الاحتياطي ويا القاعدة.

## وين بالكود
`backend-go/internal/storage/`، و`handler/file_handler.go`، و`repository/inline_files_migrate.go` (بيه القائمة الوحيدة `InlineFileColumns`)، و`frontend/src/api.ts` (`storeFile` و`fileUrl`).
