# 0011 — Claude يسجّل ساعات شغله بسجل دوام دازاي برمز وكيل
**التاريخ:** 2026-11-06 · **الحالة:** ✅ معتمد

## السياق
دازاي اتفق ويا Claude إن وقت فحص البلاغات وقراءتها وتصليحها ينحسب بسجل دوامه عن بعد. لحد هسه ينكتب بملف `docs/سجل-وقت-البلاغات.md` ودازاي ينقله بإيده، وسأل «شلون نضيف الساعات مباشرة للنظام؟».

## القرار
- رمز `REMOTE_HOURS_AGENT_TOKEN` (٣٢ حرف أو أكثر) بترويسة `X-Remote-Hours-Agent-Token`، يفتح مسار واحد: `POST /api/remote-hours/agent`. بلا الرمز أو بيه غلط = ٤٠٤.
- **الموظف ثابت من الإعدادات** (`REMOTE_HOURS_AGENT_EMPLOYEE`) وما ينرسل بالطلب، فالرمز ما يگدر يسجّل لغير دازاي.
- حدود: ساعتين بالطلب، ٦ ساعات للوكيل باليوم، يومين لورا بالكثير، ملاحظة إجبارية، و`Idempotency-Key` إجباري (نفس المفتاح ما يتكرر).
- السطر ينحفظ بمصدر `AGENT` وملاحظة تبدي بـ «🤖 Claude [المفتاح]:»، فيبين بالسجل منو سجّله.
- نفس شروط الإضافة العادية (مو بالمستقبل، مجموع اليوم ≤ ٢٤ ساعة، حساب فعّال).
- الكاتب: `scripts/remotehours.sh`؛ والفحص المجدول يستدعيه بعد كل سطر بسجل الوقت.

## النتيجة
- لو تسرّب الرمز: أقصى ضرر ٦ ساعات باليوم بسجل دازاي، كلها معلّمة «🤖 Claude» وتنمسح من الشاشة.
- الرمز ينحط بمكانين (`.env` السيرفر وبيئة Claude)، ويتبدّل بالمكانين إذا انكشف.

## وين بالكود
`handler/remote_hours_agent.go` (`AgentAdd`, `SetAgent`)، و`TestRemoteHoursAgent`.
