- حقول الإدخال `font-size: 16px`، حتى الآيفون ما يكبّر الشاشة من تضغط على الحقل.

## ٢. السكرتير: `src/pages/SecretaryPage.tsx` و`.css`
**الفكرة: تطبيق ذكاء اصطناعي مثل ChatGPT**، مو صفحة طويلة تنزل بيها.

### الهيكل
- الشاشة كاملة `100dvh`، بلا تمرير للصفحة نفسها. كل قسم يتمرّر جوّاه هو.
- **زر قائمة بالركن الأيسر الأعلى** يفتح درج جانبي من اليسار. بالشاشة العريضة (≥ ٩٠٠px) الدرج يبقى مفتوح كقائمة جانبية على اليسار.
- بنود الدرج، ويا كل بند عدّاده:
  1. 💬 **المحادثة**
  2. 📅 **جدول أعمالي**
  3. 🔔 **تذكيراتي**
  4. 📔 **مذكراتي**
- 🔴 **ماكو أي زر أو رابط يرجّع للنظام.** ينشال «النظام ↗» (`sec-system`)، وينشال كل `<Link>` لشاشات النظام («افتح التفاصيل»). كلشي ينحسم من داخل السكرتير.

### 💬 المحادثة (مثل ChatGPT)
- الرسائل تتمرّر بمكانها، وصندوق الكتابة **ثابت بالأسفل**: زر المايك + الكتابة + الإرسال.
- إذا ماكو رسائل، تطلع ترحيبة قصيرة ويا اقتراحات تنضغط، مثلاً «شنو صاير اليوم؟» و«منو متأخر؟» و«وجّه مهمة».
- «نبض اليوم» يطلع من المحادثة، وينتقل لجدول أعمالي.
- مسودة المهمة ونافذة الموعد يبقون مثل ما هم، والموعد بالمسودة **إجباري**.

### 📅 جدول أعمالي: `GET /api/secretary/agenda`
- يرجّع: `[{id, kind: 'meeting'|'guest'|'mine', title, who, note, at, doneAt}]`.
- فوق: «نبض اليوم» (`/secretary/today`، `summary.lines`).
- بعدها البنود مقسّمة **اليوم / باچر / بعدين / بلا وقت**.
- زر «➕ أضف للجدول»: نص + وقت اختياري ← `POST /api/secretary/notes` بالجسم `{kind:'AGENDA', body, at:'YYYY-MM-DDTHH:MM'}`.
- بنوده هو (`mine`) بيها:
  - «✓ خلص» ← `PUT /api/secretary/notes/{id}/done` بالجسم `{done:true|false}`.
  - «حذف» بتأكيد داخل الصفحة، ← `DELETE /api/secretary/notes/{id}`.

### 🔔 تذكيراتي: `GET /api/secretary/reminders` (موجود)
- الي ينتظر قرار أو متابعة، مقسّم: طلبات مقابلة · ضيوف · إجازات · حذف حجوزات.
- **المقابلة والضيف:** «حدد موعد» و«ارفض» (الموجودات).
- **الإجازة:** `id` يجي `leave:<id>`. «وافق» و«ارفض» ← `api.decideLeave(<id>, approve, note)`.
- **حذف الحجز:** `id` يجي `delete:<id>`. «وافق» و«ارفض» ← `api.decideBookingDelete(<id>, approve, note)`.
  - ⚠️ الموافقة **تحذف الحجز**، فلازم تأكيد ثاني داخل الصفحة («متأكد؟ الحجز ينحذف»).

### 📔 مذكراتي: `GET /api/secretary/notes?kind=DIARY&q=`
- صندوق كتابة فوق: «شنو صار اليوم؟». يحفظ بـ`POST /api/secretary/notes` بالجسم `{kind:'DIARY', body}`.
- القائمة مقسّمة حسب اليوم، الأحدث أول، ويا بحث (`q`).
- «حذف» بتأكيد داخل الصفحة.
- سطر يفهّمه إن السكرتير يكدر يرجعلها من يسأله مثل «شنو سويت ويا فلان؟» (الأداة `my_notes`).

### الألوان: «مودرن ومفهومة»
- الأرضية فاتحة نظيفة (مثلاً `#f7f8fa`)، والبطاقات بيضاء، والنص `#0f172a`، والثانوي `#64748b`.
- **لون رئيسي واحد** واضح (أزرق أو نيلي) للأزرار والبند المختار.
- لون لكل معنى، وثابت بكل الأقسام: أخضر = وافق/خلص · أحمر = ارفض/حذف · كهرماني = ينتظر.
- يُفضّل وضع ليلي بالمتغيّرات.
- البنفسجي والبيج الحاليين ينشالون، لأن دازاي ما عجبوه.

## القواعد
- ممنوع `window.prompt`. وأي تأكيد يكون داخل الصفحة.
- السكرتير للمالك والمدير بس. ما تنادي أي endpoint ثاني، حتى ما يطلع 403.
- الجلب داخل `useEffect` ويا `alive`، والتحديث برفع عدّاد (`setReload(n => n + 1)`).
- قبل الرفع: `npx tsc --noEmit -p tsconfig.app.json` و`npx eslint src` و`npm run build`، وجرّب بالموبايل والشاشة العريضة.
