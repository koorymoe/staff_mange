# ساسكي → لوفي: الهيكل التنظيمي، المرحلة ١

الفرع `avg-sasuke`، فوق `avg` عند `f077a69b` (عقد الهيكل وإصلاحات الحماية وأسماء مكاني). الواجهة فقط؛ ما تغيّر أي ملف باك إند.

## الجاهز

- `/org`: شجرة حسب parentId، إدارة عليا، الإدارة ثم الإدارات التابعة، وIT بجانبها مستقلة. المدراء والنواب والأعضاء، صور من قائمة الموظفين مع بديل حرف، الشواغر وأزرار تعيين. الإدارات قابلة للطي على الموبايل، بلا zoom بسبب الحقول (كلها 16px).
- نافذة تعيين مشتركة للشجرة والترتيب: بحث عربي موحّد، موظفون فعّالون، إدارة ثم وحدة اختيارية، منصب، مخصص بفواصل وأرقام عربية، صفر مسموح، تنبيه ومنع 1–999 بلا تحويل صامت، وملاحظة. 409 وأخطاء الخادم تبقى بالعربي بدون خسارة المسودة.
- تفاصيل المنصب: المنصب/المخصص/البداية بتوقيت بغداد/الملاحظة/بالوكالة. إنهاء بحقل سبب مطلوب وتأكيد داخل dialog؛ لا prompt ولا confirm. نافذة أصلية داخل الصفحة مع حصر التركيز وEscape وقفل الإغلاق أثناء الحفظ، وهيدر وأزرار ثابتة عند التمرير.
- صلاحيات الوحدة بأسماء `/permissions/catalog`. المفتاح غير المعروف يظهر بوصف صريح؛ فشل القاموس ما يخفيه بصمت.
- `/org/assign`: كل الموظفين الفعّالين، جميع مناصبهم، بلا مكان، عداد، فلتر بلا مكان/إدارة وبحث. العداد يعتمد المناصب الموجودة فعلاً، ما نفترض منصباً غير مسجل.
- `MyOrgCard` بالرئيسية للكل + رابط «مكاني» `/my-org`. يعتمد **فقط** `/org/me` وdivisionName/unitName؛ ما يطلب chart أو employees أو catalog. قائمة فارغة = «بعدك ما انوضعت بالهيكل»، خطأ الشبكة مو قائمة فارغة.
- الشجرة والترتيب محميتان بـRequireAdmin وحارس داخل المكون قبل effects. القائمة والمسار يحجبان الموظف حتى مع منح وحدات. غير المالك ما يشوف إجراء نهاية منصبه/منصب المالك/ADMIN، ولا يختارهم بالتعيين (حماية guard الجديدة في f077a69b). إذا فشل جلب قائمة الموظفين، لا تخمين لصلاحية تغيير منصب.
- بعد الحفظ/الإنهاء جلب جديد بلا ريفرش كامل. alive guards وتحميل منفصل للأقسام؛ فشل الهيكل أو الموظفين يعطّل التعيين وما يطلع عداد وهمي 0.
- تكامل صغير بشاشة الصلاحيات الحالية: نوع ORG ووسم «منصب بالهيكل» فقط، بدون تغيير آلية المنح أو الأدوار.

## الفحص والتسليم

نجحت tsc وeslint وbuild (تحذير chunk >500KB القديم فقط). `scripts/check-org-ui.cjs`: Chromium مع APIs مصطنعة، الشجرة/طي الموبايل، الكتالوج، 409 وحفظ المسودة، المخصص الصغير والأرقام العربية و50,000 والصفر، إزالة unitId بعد تغيير الإدارة، تعيين/إنهاء مع السبب وفشل الإنهاء وإعادته، الموظفون الفعّالون والفلاتر، قفل أهداف الأدمن، موظف عادي صفر API إداري، مكاني /org/me وحده، empty state، فشل chart/employees ثم retry، 390/1366 والليلي والنهاري وعدم تجاوز عرض الصفحة، وتباين النص الثانوي المحسوب ≥4.5. ونجح `scripts/check-permission-access.cjs` كفحص عدم تراجع للصلاحيات.

يبقى فحص لوفي/ناروتو حيّاً بالخادم مع قاعدة اختبار قبل الدمج والنشر، والتحقق من المنح والسحب الفعليين وتجديد جلسة صلاحيات الموظف؛ الاختبارات هنا تثبت سلوك الواجهة لا صحة قاعدة البيانات. لا نشر برود من ساسكي، وظهور الواجهة يحتاج دمج ونشر و`npm run build` على السيرفر.
