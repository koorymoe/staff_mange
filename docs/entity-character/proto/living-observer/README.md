# Living Observer — Golden Male Motion Gate

نموذج مستقل للنمط البصري المعتمد، ويختبر الشخصية الرجالية بالحجم الحقيقي
قبل إنتاج المكتبة: طبقات مسماة منفصلة، مشي، رمش، تلويح، واستلام وحمل وفتح
وتسليم ورقة الخصم، مع حركة مخففة وسجل حالة مرئي.

افتح `index.html` مباشرة؛ لا يحتاج build أو مكتبة أو خادماً.

## الحدود

- لا يلمس `frontend/src`.
- لا يغيّر عقد `StoryScene`.
- لا يستخدم صورة الموظف الحقيقية داخل الملف أو المستودع.
- هذا بوابة حركة للنموذج الذهبي، وليس دمجاً إنتاجياً.

## شرط القبول

لا تبدأ دفعة الشخصيات العشر حتى يعتمد (ع) الشكل والحركة معاً بالحجم الحقيقي.
