عليها عظام أو حركات. المرجع الوحيد المعتمد صار 3D animated-film mascot كبير

`frontend/src`.

## الخيارات

- A: متوازن احترافي — أعلى شبه وحضور رسمي.
- B: ماسكوت حي — رأس أكبر وحركات أوضح بالحجم الحقيقي. ترشيح (م).
- C: رفيق مصغّر — ألطف وأخف لكنه أبعد عن النسب الواقعية.

الوجه والسترة والألوان ثابتة قدر الإمكان حتى يكون الاختيار عن **النسب** لا عن
ثلاثة تصاميم مختلفة. مربع «اختبار الحجم الحقيقي» يبدل مع الاختيار.
