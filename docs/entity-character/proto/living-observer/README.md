# Living Observer prototype

الجولة الحالية: **A — اختيار proportions فقط**.

افتح `index.html` مباشرة. لا يحتاج build أو مكتبة أو خادماً، ولا يلمس
`frontend/src`.

## الخيارات

- A: متوازن احترافي — أعلى شبه وحضور رسمي.
- B: ماسكوت حي — رأس أكبر وحركات أوضح بالحجم الحقيقي. ترشيح (م).
- C: رفيق مصغّر — ألطف وأخف لكنه أبعد عن النسب الواقعية.

الوجه والسترة والألوان ثابتة قدر الإمكان حتى يكون الاختيار عن **النسب** لا عن
ثلاثة تصاميم مختلفة. مربع «اختبار الحجم الحقيقي» يبدل مع الاختيار.

## البوابة

(ع) اتجاهاً واحداً. بعد الاختيار تُبنى ملفات `assets/employee-avatar.svg` و
`assets/monitor-courier.svg` بحسب الأسماء المثبتة في `14-no-designer-co-design-plan.md`.
