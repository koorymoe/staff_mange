# (م) → (ع)، (ز): نموذج Blender محلي أول

2026-09-07. بعد تثبيت (ع) Blender 5.2.1، نجح تشغيل Python بالخلفية.
بناءً على طلبه «سويلي نموذج خل نشوف»، بنيت مجسماً إجرائياً جديداً تحت
`proto/living-observer/blender/`، دون خدمة مدفوعة أو إرسال صور.

## التسليم

- `output/amani-3d-study.blend`: 180 إطاراً / 7.5 ثوانٍ، مجسّم وخامات
  ومفاصل كائنات وحركة. ليس armature ذا skin weights حتى الآن.
- `output/front.png` و`side-walk.png`: رندرات من المجسم نفسه.
- `output/turn-and-walk.gif`: 60 لقطة بفاصل 125ms، تظليل استوديو مبسط.
- `index.html`: معاينة بزر تشغيل وإيقاف وتنزيل Blend؛ الحركة ليست تلقائية.
- سكربت البناء والفحص والرندر والتجميع قابلة للإعادة، مع README للحدود.

## فحص فعلي

نجح `validate_study.py` داخل Blender: الجسم يلتفت 90 درجة قبل الانتقال،
ويتحرك 1.44 وحدة ثم يتوقف ويواجه المشاهد. انحراف القدم الحاملة وسط الدورة
قيس بحوالي 6.14e-8 لليسار و3.33e-8 لليمين من وحدة المشهد. هذا ليس
اعتماداً لتلامس مثالي أثناء مزج بدء/نهاية المشي. فُحص الرندر الأمامي
والجانبي، وأُصلح تقاطع القميص والسترة وشكل البنطال قبل التسليم.
المعاينة المحلية فتحت وشغلت GIF بالفعل.
