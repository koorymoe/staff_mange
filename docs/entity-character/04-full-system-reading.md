# برنامج قراءة النظام كاملاً — لـ(م)

طلب **(ع)** صريح: *«اريده يقره النظام سطر سطر من أول سطر إلى الي
واصلين إله، وكل شي احنا متفقين عليه — حته نشتغل سوه ويطلع أقوى نظام»*.

هاي مو دعوة تصفّح. **اقرا النظام كله**، بهذا الترتيب، وطلّع مخرجات
مكتوبة — حتى نعرف إنك قريت فعلاً، ونستفيد من الي تلگاه.

## ② العمود الفقري للخادم

بهذا الترتيب:
1. `backend-go/cmd/api/main.go` (١٬٥٨٨ سطر) — **كل مسار وحارسه**.
   اقراه سطر سطر؛ هو خريطة النظام كله.
2. `internal/middleware/` (٨٨٢ سطر) — `auth.go` خصوصاً:
   `RequireRole` · `RequireRoleOrAnyPermission` · استخراج الهوية.
3. `internal/model/permission.go` — `RoleDefaultPermissions` وكل
   الصلاحيات المعرّفة.
4. `internal/config/` · `internal/timeutil/` · `internal/storage/` ·
   `internal/safeguard/` (صغار، اقراهم كاملين).

**المخرج** → `notes/02-backend-spine.md`: جدول **كل مسار → حارسه →
منو يوصله فعلاً**. ⚠️ وأي مسار **بلا حارس صلاحية** (لگينا وحدة
هيج فعلاً: `GET /api/audit-issues` چان مفتوحاً لأي موظف مسجّل).

## ⑧ قواعد المخرجات (مهمة)

1. كل ملاحظاتك تحت `docs/entity-character/notes/` على فرع
   `entity/design-talk`. **صفر لمس** لـ`backend-go/` أو
   `frontend/src/`.
2. **لا تصلّح شي وأنت تقرا.** سجّل الملاحظة وكمّل. الإصلاح يجي
   بجولة لها خطتها وموافقة (ع).
3. ⚠️ **رقم غلط أسوأ من ماكو رقم.** لو ما قِست، اكتب «ما قِست».
   ولو ما متأكد إن شي عطل، اكتبه تحت «شكوك» لا تحت «أعطال».
4. رتّب كل عطل بثلاثة: **شنو ينكسر** · **على منو** · **كيف يُثبَت**.
   بلا «كيف يُثبَت» الملاحظة رأي مو اكتشاف.
5. ادفع بعد كل مرحلة، لا تنطر السبع. أني أراجع أول بأول.
   ⚠️ واستعمل `git commit -F <ملف>` — رسائلك توصل
   `System.Collections.Hashtable.Message` (شِل PowerShell يبلعها).
