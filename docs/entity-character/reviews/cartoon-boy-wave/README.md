رفعها المالك للمراجعة على entity/design-talk فقط. لا تدمجها أو تنشرها تلقائياً إلى prod. هذه نفس النسخة المعروضة محلياً، وليست الشخصية النهائية.

## الملفات والتشغيل

- amani-wave.glb: الشخصية مع حركة التلويح التجريبية، نحو 21 MB.
- amani-wave.blend: مصدر التعديل، Blender 5.2.1 LTS؛ افتحه مع تعطيل تنفيذ السكربتات المضمنة. لا تنشر blend على السيرفر.
- avatar-review.html وملفات mjs: معاينة Three.js، تتطلب اتصالاً لتحميل Three.js 0.180.0 من jsDelivr.
- شغّل `node serve.cjs` من هذا المجلد ثم افتح `http://127.0.0.1:5198/avatar-review.html`.
- الاختبارات: `node --test --test-isolation=none gaze-math.test.mjs`.

## ملاحظات المالك غير المحلولة — مهمة

1. الكف يلوّح جانبياً ولا يواجه المشاهد بالشكل المطلوب؛ يحتاج ضبط اتجاه الكتف والساعد والكف.
2. الأصابع واليد المتدلية مستقيمة ومشدودة؛ وضعية الراحة لم تُضبط بعد.
3. الوقفة تبدو روبوتية؛ يلزم ثني خفيف وتوزيع وزن طبيعي.
4. المشي والأصابع والجفون النهائية لم تكتمل. تتبّع العينين تجريبي وقت التشغيل، ليس ذكاءً اصطناعياً.
5. الخامات تستخدم إصلاح شفافية داخل المعاينة؛ تحميل GLB وحده بعارض آخر قد يظهر اختلافاً. افحصها قبل الدمج.

التلويح يعمل مرة واحدة مع الرجوع للوقفة وشريط فحص، لكن جودة الحركة ليست معتمدة. فحص المتصفح نجح بلا أخطاء تشغيل ونجحت 4 اختبارات حسابية، وهذا ليس اعتماداً بصرياً كاملاً.

لا تعديل على كود النظام ولا دمج مساعد ذكي ضمن هذه الرفعة. الأصل تنزيل المالك من TurboSquid (Cartoon boy rigged Free، رقم 2264481). الترخيص الكامل لم يُراجع؛ مجانية التنزيل ليست إثبات حق إعادة التوزيع أو الاستخدام الإنتاجي. راجع الترخيص قبل النشر النهائي.
