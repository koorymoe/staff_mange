# إلى ز — مراجعة شخصية أماني

طلب (ع) مشاركة هذه النسخة معك للمراجعة. هذه ليست نسخة إنتاج أو نتيجة نهائية.

- افتح `amani-studio-review.blend` في Blender 5.2.1. الخامات الثلاث المستخدمة مضمّنة، بدقة 512×512.
- `hero.png`: لقطة ملوّنة. `WALK_TO_TARGET.gif`: عينة المشي بكاميرا تتبع الشخصية. `motion-overview.jpg`: عينات ثابتة من المقاطع الـ11.
- شخصية واحدة، 41 عظمة، 50,432 رأسًا. إعادة فتح الملف والتحقق أثبتا أن هندسة الجسم وأوزانه تطابق المدخل الأصلي.
- أسماء العظام متوافقة بين المدخل والحركات لكن أوضاع الراحة مختلفة. نُقلت اتجاهات المقاطع إلى هيكل الشخصية مع مراعاة دوران العظام حول محاورها. المقاطع الأصلية محفوظة بأسماء تبدأ بـ `SOURCE_` للمقارنة؛ النقل يحتاج تدقيقًا بصريًا كاملًا خصوصًا الكفين والكتفين وتلامس القدمين.
- المقاطع العاملة: WALK_TO_TARGET, WALK_ALT, RUN_TO_EDGE, SPEAK, SPEAK_ALT, CELEBRATE, SIT_IDLE, SIT_SPEAK, LAYING_IDLE, SHOW_WARNING, POINT_AT_UI. تُختار من Action Editor، مع ضبط نطاق الخط الزمني لكل مقطع. BASE_REFERENCE وضعية المرجع الواردة.
- تمدد السترة تحت الإبط عند رفع الذراعين ما زال موجودًا. تجربة إزالة تأثير الأذرع بحسب لون القماش رُفضت لأنها سببت شدًا عند الحدود؛ لم تُعتمد في هذا الملف.
- لا يوجد تتبع للماوس ولا تحكم مستقل بالعينين ولا facial shape keys أو lip-sync. طلب (ع) إضافة تتبع العين للمؤشر لاحقًا؛ لم يُنفذ بعد.
- لا يوجد ربط بالنظام أو تعديل على الإنتاج. أسماء الإجراءات مأخوذة من سكربت merge.py المرسل، وليست إثباتًا بأن التكامل تم.

يرجى مراجعة الألوان والـUV والحركات، وتحديد العيوب المرئية قبل اعتماد أي نسخة للتطبيق. احتفظ بهذه النسخة منفصلة عن عملك الأصلي.
