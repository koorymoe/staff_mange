# تسليم ساسكي — إعادة تصميم السكرتير والدخول

الفرع: `avg-sasuke`، مبني فوق `a37e2e02` من `avg`.

- شاشة دخول ثابتة: شيل إمالة الماوس ونبض الحلقات والشعار والفقاعات والنقاط، وحقول 16px.
- سكرتير بارتفاع الشاشة: درج من اليسار بالموبايل، ثابت من 900px، وأربع أقسام بعدادات.
- المحادثة تتمرّر داخلياً، والمايك والكتابة ثابتان؛ اقتراحات قابلة للإرسال بالمحادثة الفارغة.
- جدول أعمالي مربوط بـ`agenda` و`notes`: نبض اليوم، اليوم/باچر/بعدين/بلا وقت، إضافة، إنجاز، وحذف بتأكيد.
- تذكيراتي: تحديد موعد/رفض للمقابلات والضيوف، موافقة/رفض للإجازات وحذف الحجوزات. حذف الحجز ما ينفّذ قبل التأكيد الثاني.
- مذكراتي: حفظ، بحث مع حماية سباق الطلبات، تجميع حسب اليوم، وحذف بتأكيد. مسودات الجدول والمذكرات منفصلة.
- موعد مسودة المهمة إجباري. المواعيد المعروضة والمقترحة بتوقيت بغداد.
- شيل كل روابط الرجوع للنظام من واجهة السكرتير وبطاقاته. ألوان فاتحة وأزرق رئيسي، وأخضر/أحمر/كهرماني للمعاني، ومتغيرات لليل.
- أيقونات التثبيت والـmanifest متناسقة مع اللون الجديد.

## الفحص

TypeScript وeslint والبناء. فحص Chromium بعرض 390×844 و1366×900: ارتفاع الشاشة والتمرير الداخلي، الدرج، الاقتراحات، إضافة وإنجاز الجدول، حفظ/بحث/حذف المذكرات، قرار الإجازة، تأكيد حذف الحجز مرتين، وملء موعد المقابلة من UTC إلى بغداد. تحقق من ثبات بطاقة الدخول مع الماوس، توقف أنيميشن العناصر المطلوبة، وخط 16px.

فحص المتصفح استعمل ردود API اختبارية بنفس العقد؛ الربط الحي بقاعدة الشركة والصوت الحقيقي يفحصه ناروتو عند الدمج. صور المعاينة بيانات اختبارية فقط، داخل `docs/secretary-previews/`.

ماكو تعديل باك إند أو ترحيلات بهذه الدفعة. الرفع على `avg-sasuke`؛ الدمج والنشر عند ناروتو حسب قرار دازاي.
