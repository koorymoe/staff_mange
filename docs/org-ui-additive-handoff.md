# ساسكي → لوفي: ترتيب إضافي بلا إلغاء + مصدر مشاكل المكتب (11-01)

الفرع `avg-sasuke` مدموج وياه avg `847ea0fd`. كل شغل لوفي الأخير (الفواتير، مراحل المشاريع، حارس التقييم، إشعارات وإجراءات المراقب، وبحث تقارير العمل) محفوظ مثل ما هو. تعارض سجل التسليم انحل بالاحتفاظ بالسجلين. لا تغيير باك إند أو ترحيلات أو صلاحيات من ساسكي.

## القاعدة الذهبية مطبّقة

- عكس ترتيب 10-30 الذي كان ينقل المداخل: التجميع هسه **إضافي**. شجرة المداخل القديمة بعد فلترتها تبقى كاملة بنفس الكائنات والمواقع والفواصل والأزرار، وتلحقها مجموعة «الوحدات حسب الهيكل الجديد». ما انحذف أي مدخل قديم أو مجموعة قديمة.
- الاختصارات الجديدة نسخ من الروابط الظاهرة فعلاً للشخص فقط، بحراسها الأصلية: permission/roles/unitPermission/strict/hideForRoles/monitorMenuHide، مع سياق granted الأصلي. لا إعادة منح ولا تجاوز بوابة وحدة. إزالة التكرار داخل **النسخ الجديدة فقط**؛ مو داخل الشجرة القديمة.
- عناوين الوحدات حسب OrgSeed: مراقبة الوحدات، الحسابات، الرقابة، التدقيق، العُدد والمركبات، إدارة الكوادر، الحجوزات والتنسيق، التقنيين والخدمات، التدريب، إدارة المشاريع، التصميم، متابعة الجودة والشكاوي، المشتريات والمخزن، الإعلام والعلاقات العامة، التقنية IT. المجموعة الجديدة الفارغة لا تُنشأ؛ الشجرة القديمة لا تتأثر.
- الحجوزات والتنسيق تجمع روابطها المسموحة مع بقاء مداخلها القديمة. التدقيق يجمع شاشات التدقيق الموجودة (بلاغات الأخطاء والتكرار وفواتير الليدر وتدقيق تنسيق الحجوزات، كل واحدة بحارسها الموجود). ما أضفت مسار تدقيق مخمّن أو حوّلت حارس المالية إلى auditing. الحسابات المالية تبقى أيضاً بمكانها.
- الروابط to للصفحات ما تغيّرت، والـquery جزء من الهوية (الفاتورة الاستفسارية مو نفس الفاتورة المرتبطة). مفاتيح أزرار المجموعات الإضافية تستعمل `/org-nav/...` عند احتمال اصطدامها بمفتاح قديم؛ هاي أزرار فتح بالقائمة فقط، **مو صفحات أو routes جديدة**.
- «🏛️ مكاني» و«🏛️ مكتب الإدارة» باقيات فوك وبنفس الحراس. الدخول المباشر يفتح مجموعة الهيكل الجديدة والمجموعة القديمة أيضاً إذا موجودة. لا تغيير بحارس الرابط `isPathAllowed` أو `isNavVisible` أو تعريفات raw navItems.

## مصدر مشاكل المكتب

- `issues[].source === 'MATRIX'`: «🤖 شخّصها ماتركس».
- `source === 'MONITOR'`: «👁️ من المراقب».
- HUMAN أو null أو قيمة غير معروفة لا تتحول إلى ماتركس أو مراقب بالتخمين. الحقل اختياري بواجهة TypeScript للتوافق مع الردود القديمة.
- إضافات نصية داخل رأس كارت المشكلة، بلا إخفاء العنوان أو الكاتب أو الخطورة أو الحالة أو خطة الحل أو التعليقات أو أي زر قديم. ألوان من desk-badge الموجودة، نهاري/ليلي، والتباين المقاس ≥4.5:1. لا API جديد.

## جدول قبل / بعد — ولا عنصر ناقص
