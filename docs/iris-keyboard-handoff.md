# ايريس — الكتابة والكيبورد (ساسكي)

الفرع: `avg-sasuke`. تعديل واجهة فقط؛ لا تغيير بالباك إند أو عقد API.

- ارتفاع وموقع صفحة ايريس يتبعان `visualViewport` عند فتح/غلق الكيبورد وتحريك Safari للنافذة. المستمعات تنشال عند مغادرة الصفحة.
- عند ظهور الكيبورد، الفراغ أسفل صندوق الكتابة 4px بلا إضافة safe-area ثانية أو تذييل.
- الرسالة النصية تظهر فوراً قبل انتظار API، ويا «ايريس يفكّر…». الرد يضاف بدون تكرار رسالة المستخدم. فشل الإرسال يرجع النص للخانة ويظهر الخطأ، وليس نجاحاً وهمياً.
- وصول سجل المحادثة المتأخر لا يمسح الرسالة المضافة محلياً.

الفحص: TypeScript وESLint والبناء و`git diff --check`، ومتصفح Chromium على Vite مع بيانات اصطناعية وAPI وهمي. نجح تأخير الرد المتعمد، الظهور الفوري، عدم التكرار، وفشل الإرسال واسترجاع النص. نجحت محاكاة viewport بارتفاع 440px وoffsetTop=20px ثم استرجاع 844px، وفراغ الكتابة 4px. كذلك فحوص المرجع السابقة للموبايل/الديسكتوب والليلي والصلاحيات.

هذه محاكاة كيبورد، وليست تجربة آيفون فعلي. قبل الترقية: ناروتو يفحص Safari والتطبيق المثبت، فتح/غلق الكيبورد وتدوير الجهاز، على الباك إند الحقيقي. لا شيء انرفع إلى `prod`؛ يحتاج الدمج والبناء بالسيرفر بعد الموافقة.
