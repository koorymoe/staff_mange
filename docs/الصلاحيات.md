# دليل الصلاحيات — نظام شركة الأماني

مرجع كامل لكل صلاحية موجودة بالنظام: شنو تفتح، ومنو ياخذها افتراضياً.

> تحديث: ٣١ / ٧ / ٢٠٢٦ — ٣٣ صلاحية.
> **ملاحظة عامة:** مدير النظام (ADMIN) والمالك (OWNER) عدهم وصول كامل دائماً، ما يحتاجون أي صلاحية من هذي.

## ١. إدارة الموظفين

| الصلاحية | شنو تفتح |
|---|---|
| `staff_management` | إدارة الكوادر — إضافة وتعديل الموظفين ومهاراتهم |
| `edit_employee_profile` | تعديل ملف الموظف (الراتب / الدوام / الإجازات) |
| `kpi_management` | تقييم الأداء (KPI) |
| `kpi_criteria_management` | إدارة نقاط الكي بي اي (إضافة / حذف) |
| `inventory` | جرد الأدوات — إدارة العدة الشخصية وأدوات المركبات والعدة القياسية |
| `tool_requests_approve` | **موافقة / رفض طلبات الأدوات** (صلاحية مستقلة — أنظر الملاحظة تحت) |

> **مهم — `tool_requests_approve`:** قبل، الموافقة على طلبات الأدوات كانت مربوطة بالدور الوظيفي فقط (مدير النظام / إداري الكوادر / المراقب) بدون أي منفذ صلاحية. يعني **إداري الكميات — وهو صاحب الشغلة أصلاً — ما كان يقدر يوافق مهما انمنحت له صلاحيات ثانية**. هسه انفصلت وتنمنح لأي موظف لوحدها.
>
> **الحذف** مو داخل بهذي الصلاحية — حذف طلب الأداة نهائياً محصور بمدير النظام والمالك فقط.

## دورة طلب الأداة — من الطلب للمحاسب

١. **الموظف (ليدر)** يفتح «طلب أداة» ويختار الأداة.
٢. تنفتحله نافذة تسأله **شنو السبب؟** — قائمة منسدلة إجبارية:
   - الأداة الي عندي **تالفة**
   - الأداة الي عندي **ضايعة**
   - الأداة مستهلكة من كثر الاستعمال
   - الأداة مسروقة
   - ما عندي هذي الأداة أصلاً
   - أحتاج نسخة إضافية لطبيعة الشغل
   - سبب آخر *(الشرح إجباري بهذي الحالة)*
٣. يكتب **شرح المشكلة** (اختياري إلا مع «سبب آخر»).
٤. **إداري الكميات** يشوف الطلب بجدول «طلبات الأدوات» مع السبب والشرح كاملين، ويضغط «موافقة»:
   - **الأداة موجودة بالشركة** ← تنصرف من المخزن مباشرة، خلصت.
   - **الأداة مو موجودة** ← لازم يشتريها، فالنظام **يطلب منه سعر الشراء**، وبعدها يفتح **طلب مشتريات تلقائياً يوصل للمحاسب** مع اسم الأداة وسعرها والسبب والشرح.
٥. الطلب المتعامل معه **ما ينعاد** — أي محاولة موافقة ثانية تنرفض.

> الموظف يقدر يطلب أداة **حتى لو مو متوفرة بالمخزن** — لأن هذي بالضبط الحالة الي إداري الكميات يشتريها بيها.

## العدة القياسية والجرد

- **العدة القياسية** قائمة رئيسية بأسماء الأدوات الي المفروض تكون عند **كل موظف**.
- أي أداة تنضاف للعدة القياسية **تنضاف فوراً لعدة كل الموظفين الحاليين**، وأي موظف جديد ياخذ القائمة كاملة تلقائياً وقت إنشاء حسابه.
- الموظف يقدر يزيد على عدته أدوات خاصة بيه — يعني كل موظف ممكن تكون عنده **عدة زايدة أو ناقصة**، بس العدة القياسية موجودة عند الكل.
- من صفحة **«جرد أدواتي»** الموظف يشوف كل أدواته بقائمة وكدام كل وحدة علامة صح — يشيل الصح عن الأداة الماموجودة قبل ما يطلع للحجز، وتنسجل النتيجة للإداري.
- إدارة العدة القياسية بصلاحية `inventory` أو دور إداري الكوادر / مدير النظام.
