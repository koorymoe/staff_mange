دليل استخدام النظام — إداري الكميات (PROCUREMENT_ADMIN)

هذا الدليل يشرح شغلك بالضبط داخل نظام شركة الأماني، خطوة بخطوة، وبالأسماء الحقيقية للصفحات والأزرار الموجودة فعلاً بالنظام.

== شنو شغلك بالمختصر ==
أنت المسؤول عن توفير المواد والأدوات اللي يطلبها الموظفين الثانيين (الفنيين، مدراء المشاريع...)، وعن إدارة جرد الأدوات (inventory) وطلبات الأدوات (tool requests) والموردين (suppliers).

== 1. طلبات المواد والمشتريات — الصفحة الرئيسية لشغلك ==
المسار: من القائمة الجانبية ← الإدارة ← إدارة المشتريات ← "طلبات المواد" (رابط /procurement).

بهذي الصفحة تشوف كل طلبات المواد المقدّمة من الموظفين، مقسّمة على تبويبين بالأعلى:
- تبويب "طلبات منتجات الزبائن" (CUSTOMER_PRODUCT): طلبات مواد مرتبطة بحجز زبون معيّن — مثلاً فني طلب مادة ناقصة لتنفيذ شغلة عند زبون. هذا التبويب فيه عمود إضافي يوضح رقم الحجز واسم الزبون.
- تبويب "طلبات احتياجات شخصية" (PERSONAL_SUPPLY): طلبات مواد أو أدوات شخصية للموظف نفسه، مو مرتبطة بزبون.

كل طلب بالجدول يظهر: الكود، مقدم الطلب، الحالة (بانتظار التوفير / جاري التوفير / تم التوفير / مرفوض)، التكلفة، التاريخ. اضغط على أي صف يوسّعه ويوريك تفاصيل المواد المطلوبة (اسم المادة، الكمية، سعر الوحدة إذا محدد).

== 2. شلون تتعامل مع طلب جديد (توفير المواد) ==
بما إنك إداري كميات، عندك صلاحية كاملة للتحكم بحالة أي طلب. الأزرار تظهر بعمود "إجراءات":

الخطوة 1: إذا الطلب "بانتظار التوفير" (PENDING)، عندك خيارين:
  - زر "جاري التوفير" (يحوّل الحالة IN_PROGRESS) — اضغطه لما تبدي فعلياً تدوّر/تشتري المادة.
  - زر "رفض" — إذا المادة مو متوفرة أو الطلب غير منطقي.

الخطوة 2: لما تجهّز المواد فعلياً، اضغط زر "تم التوفير" (يفتح نافذة "تنفيذ الطلب"):
  - لكل مادة بالطلب فيه صندوق فيه: اسم المادة والكمية المطلوبة، خانة اختيار "تم التوفير" (علّمها لكل مادة وفّرتها فعلاً)، حقل "سعر الوحدة"، وحقل "الإجمالي" لكل مادة.
  - تحت فيه حقل "التكلفة الإجمالية" للطلب كامل، وحقل "ملاحظات التوفير" (اكتب فيه أي ملاحظة، مثلاً اشتريت من مورد معيّن أو المادة بديلة).
  - اضغط "تأكيد التوفير" لإنهاء العملية. الطلب يتحول لحالة "تم التوفير" (FULFILLED).

== 3. الفرق بين نوعي الطلبات ==
- "طلب لنفسي" (PERSONAL_SUPPLY): الموظف يحتاج أداة/مادة لنفسه، ما له علاقة بزبون معيّن.
- "طلب للزبون" (CUSTOMER_PRODUCT): مرتبط بحجز زبون محدد — عادة الفني يضغط زر "اطلب مادة ناقصة لهذا الحجز" من صفحة مهامه فينفتح نموذج الطلب مربوط تلقائياً بالحجز.
أنت نفسك تقدر تسوي طلب جديد من زر "+ طلب جديد" أعلى الصفحة، تحدد النوع (إذا عندك صلاحية الاثنين)، وتضيف المواد المطلوبة (اسم المادة + الكمية) بالضغط على "+ إضافة مادة".

== 4. الإحصائيات أعلى الصفحة ==
فيه 4 بطاقات: إجمالي المصروفات، عدد الطلبات المعلقة، عدد الطلبات اللي تم توفيرها، ومصروفات الشهر الحالي — راقبها لمتابعة أداء التوفير بشكل عام.

== 5. جرد الأدوات (Inventory) ==
المسار: الإدارة ← إدارة الموظفين ← "جرد الأدوات" (رابط /inventory).
هذي الصفحة تلمّ كل أدوات الشركة: أدوات شخصية موزعة على الفنيين، أدوات مركبات، وأدوات "عند الطلب" (on-demand) اللي الموظفين يطلبونها.
كإداري كميات، عندك صلاحية إدارة الأدوات "عند الطلب" تحديداً — تقدر:
  - تشوف طلبات الأدوات (Tool Requests) الواردة من الموظفين وحالتها (بانتظار الموافقة / تمت الموافقة / مرفوض / تم الإرجاع).
  - توافق على طلب أداة أو ترفضه.
  - تسجّل رجوع أداة بعد ما الموظف يرجّعها (return).

== 6. جرد أدواتي الشخصية (إذا عندك أدوات مسجلة باسمك) ==
المسار: /my-inventory — فيها 4 تبويبات:
  - "جرد أدواتي": قائمة أدواتك الشخصية، تأشّر عليها وحدة وحدة قبل ما تطلع بمهمة، وتضغط "تأكيد الجرد" (حتى لو فيه نقص، يرسل تبليغ للإدارة).
  - "أدوات السيارة": عرض فقط لأدوات المركبة المخصصة.
  - "طلب أداة": تشوف الأدوات المتوفرة "عند الطلب" وتضغط "طلب هذه الأداة" لو محتاجها.
  - "طلباتي": متابعة حالة طلبات الأدوات اللي قدّمتها إنت شخصياً.

== 7. الموردون (Suppliers) ==
المسار: الإدارة ← إدارة المشتريات ← "الموردون" (رابط /suppliers). فيها تدير قائمة الموردين اللي تتعامل معهم لتوفير المواد.

== 8. أين تجد الصفحات بسرعة ==
كل صفحاتك تحت قائمة "الإدارة" الجانبية:
  - إدارة المشتريات ← طلبات المواد، الموردون
  - إدارة الموظفين ← جرد الأدوات
بالإضافة لصفحات عامة بره القائمة: "تصنيفي" (/my-ranking) و"جرد أدواتي" (/my-inventory) إذا عندك أدوات شخصية مسجلة.

== نصائح عملية ==
- دايماً علّم "تم التوفير" فقط بعد ما توفر المادة فعلياً، مو قبل — حتى الفني ما ينطر شي غير موجود.
- استخدم حقل الملاحظات بنافذة التوفير لتوثيق أي بديل أو تفصيل مهم، يفيد المحاسبة والمراجعة لاحقاً.
- تابع تبويب "بانتظار التوفير" يومياً حتى ما تتراكم الطلبات وتعطل شغل الفنيين بالحجوزات.
