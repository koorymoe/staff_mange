دليل استخدام النظام — مدير مشاريع (PROJECT_MANAGER)

== شنو شغلك بالمختصر ==
تدير دورة حياة المشاريع من أول اتصال بالزبون لين التنفيذ والإكمال، وتطلب كادر فني للمشاريع لما تحتاج.

== 1. صفحة المشاريع ==
المسار: الإدارة ← إدارة المشاريع ← "المشاريع" (/projects).

المشاريع تمر بمراحل (STAGES) معروضة كبطاقات إحصائية بالأعلى:
  📞 اتصال ← 🔍 كشف ← 💰 سعر ← 🛠️ تنفيذ ← ✅ مكتمل (وفيه مسار جانبي ❌ مرفوض بأي وقت).

بما إنك مدير مشاريع عندك صلاحية إدارة كاملة (canManage):
- زر "+ مشروع جديد" لإضافة مشروع.
- لكل مشروع بالقائمة: زر "تعديل ✏️" لتحديث بياناته، وزر "حذف".
- زر "ترحيل ⮕" ينقل المشروع للمرحلة التالية بالتسلسل.
- زر "رفض" ينقل المشروع لحالة مرفوض بأي وقت إذا الزبون ألغى أو المشروع مو قابل للتنفيذ.
- أزرار "تقرير الزيارة" و"استمارة الكشف" لتسجيل تقارير ميدانية مرتبطة بالمشروع.

تقدر تصفّي المشاريع حسب المرحلة من الأزرار بالأعلى، أو تبحث بالاسم/الكود من مربع البحث.

== 2. استلام حجوزات لمشاريع ==
بالصفحة نفسها فيه قسم يعرض حجوزات معلّمة "تحويل لمشاريع" (transferToProjects) ولسه ماكو مشروع مربوط بيها — اضغط "استلام" على أي حجز حتى تربطه بمشروع جديد وتبدي تتابعه.

== 3. طلبات الكادر ==
المسار: الإدارة ← إدارة المشاريع ← "طلبات الكادر" (/staff-requests).
لما تحتاج فريق فني لمشروع بموعد معين:
  - اضغط "+ طلب كادر جديد".
  - حدد موعد الحاجة للكادر، مدة الشغل بالساعات، اربطه بمشروع (اختياري)، واختر الفنيين المطلوبين من القائمة (فقط الفنيين الفعالين تظهر أسماؤهم).
  - اكتب ملاحظات إذا محتاج معدات أو تفاصيل خاصة.
  - اضغط "إرسال الطلب لإدارة الكوادر" — الطلب يروح لإداري الكوادر (HR_COORDINATOR) للموافقة والتنسيق مع الفنيين.
تقدر تتابع حالة كل طلب قدمته (قيد الانتظار / تمت الموافقة / مرفوض / تم التلبية) بنفس الصفحة.

== 4. مصاريفي ==
المسار: /my-expenses — سجّل أي مصروف يخصك كمدير مشاريع (نقل، مواد صغيرة...) وتابع حالته.

== نصائح عملية ==
- رحّل المشروع لمرحلته التالية أول بأول حتى الإحصائيات بالأعلى تعكس الوضع الحقيقي.
- اربط طلب الكادر بالمشروع دايماً (لو موجود) حتى إداري الكوادر يعرف السياق ويسهل التنسيق.
- استخدم "تقرير الزيارة" و"استمارة الكشف" بدل ما توثق الملاحظات بمكان ثاني — كلها مربوطة بملف المشروع مباشرة.
